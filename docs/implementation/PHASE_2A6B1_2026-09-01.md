## The v3 family as a proven mechanical port

The full seven-contract family was re-issued at major 3 — runtime
(`identity_v3`, `ledger_v3`, `persistence_v3`, `contracts_v3`), seven
schemas, seven examples, and the standalone validator — with the complete
delta enumerated as data in `tests/test_v3_structural_equivalence.py`:

- platform enum widened by exactly one reviewed unit (`S2C`; `S2D+` still
  fails closed);
- identity domain strings, ID prefixes, and `schema_version` moved to the v3
  major, so identical physical inputs produce disjoint v2/v3 identities;
- the persistence transition policy now declares
  `legacy_serialization: v1_v2_forbidden_audit_only`; and
- documentation headers plus the validator's appended v2-isolation section.

The equivalence test regenerates every ported file from its byte-identical
v2 source through those ordered replacement pairs and requires exact
equality, so a reviewer audits the pair list instead of ~4,600 ported lines,
and any hand edit to either side fails the gate. The same specification was
used to generate the files, and the test additionally proves the v2 sources
contain no v3 token — nobody edited v2 in place. During development the
framework caught exactly the class of defect it exists for: a policy token
applied before the blanket rule was silently rewritten
(`v1_v2...` → `v1_v3...`) and surfaced as a one-line test failure before
commit.

The v3 examples could not be text-ported because every identity changes with
the major; `docs/contracts/phase2a/generate_v3_examples.py` regenerates them
deterministically through the v3 runtime itself, reproducing the v2 fixture
scenario with the second same-day datatake deliberately **Sentinel-2C**
(origin observation on an S2A datatake, split triggered by two S2C
observations, fully reconciled ledger and sealed state). The pytest gate
requires the committed examples to equal `build_documents()` output byte for
byte, and `validate_v3_contracts.py` passes: 7 schemas and 7 examples valid;
semantic, v1, and v2 isolation checks passed.
